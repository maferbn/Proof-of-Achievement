================================================================================
                          DESIGN SUMMARY
================================================================================

Stack:
  • OpenZeppelin v4.0.0 (ERC721 + AccessControl)
  • Hardhat + TypeScript
  • Solidity >=0.8.0

Architecture:
  • One relayer wallet per admin
  • MINTER_ROLE guards badge creation
  • Soulbound: no transfers after mint
  • Off-chain: group logic in PostgreSQL
  
Gas Optimization:
  • No redundant storage
  • Minimal access control checks
  • Simple sequential token IDs
